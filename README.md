# Dependency Visualizer

Инструмент визуализации графа зависимостей для менеджера пакетов.

## Этап 1. Минимальный прототип с конфигурацией

### Возможности

- CLI-приложение с настраиваемыми параметрами.
- Вывод всех параметров в формате ключ-значение.
- Обработка ошибок для всех параметров.

### Параметры командной строки

| Параметр | Описание |
|----------|----------|
| `--package` | Имя анализируемого пакета |
| `--repo` | URL-адрес репозитория или путь к файлу тестового репозитория |
| `--test-mode` | Режим работы с тестовым репозиторием |
| `--output` | Имя сгенерированного файла с изображением графа |
| `--ascii-tree` | Режим вывода зависимостей в формате ASCII-дерева |
